# RAWMate

RAWMate 是一款本地运行的 Windows JPG + RAW 照片去留筛选器。它用 JPG 做判断，并在统一清理时按决定保留 JPG、同名 ARW、两者或都不保留。

RAWMate 只负责决定照片留不留；挑完以后，可以继续处理 RAW，也可以直接使用 JPG。

当前版本：`1.5.1`（Windows FileVersion `1.5.1.0`，ProductVersion / 界面 `1.5.1` / `v1.5.1`）。

1.5.1：选择目录作为“集合根目录”，后台递归汇总所有子目录的 JPG/JPEG/ARW。日期目录中的同名照片独立显示、独立挑片；配对保留相对目录 scope，仅移除直接父目录 jpg/jpeg/raw/arw 一层。刷新也递归并强制重读 GPS。浏览不会移动照片；“创建分类”在每个未分类照片自己的父目录内生成 jpg/arw，“取消分类”还原到类型目录自己的父目录，不合并日期目录。冲突保留原位，成功项迁移决定/选择/当前照片与 GPS 来源；后台支持取消剩余。

1.5 新增 JPG GPS 工作流：在左下角“设置 → GPS / 元数据”显式选择本机 ExifTool 13.59；不下载、安装或捆绑工具。单张可设为来源/应用，网格可对所选 JPG 一次确认应用，默认只补缺失 GPS，已有位置必须主动授权覆盖。逐张临时副本、完整性验证及原子替换，失败保持原片并保留恢复材料。来源仅当前会话有效；“刷新目录”强制重读 GPS 并更新/清除来源，无须重启。不写 ARW / XMP，不复制 GPS 时间；未配置工具只影响 GPS 写入。Sony JPG 原无 GPS IFD 时仍须通过严格结构证明，未知布局会被安全拒绝。详见 [JPG GPS 与 ExifTool 配置](docs/GPS_METADATA.md)。

## 一次挑片怎么走

相机同时保存 JPG 和 ARW 时，可以把整批照片放进同一个目录，然后交给 RAWMate：

1. 选择照片目录，点击“创建分类”。RAWMate 会把 JPG/JPEG 放进 `jpg`，把 ARW 放进 `arw`。
2. 在图库里只看 JPG。按 `P` 保留 JPG+RAW，按 `J` 仅保留 JPG，按 `R` 仅保留 RAW，按 `X` 或 `Delete` 两种都不要；这些操作只保存决定，不会立即移动照片。
3. 全部照片都有决定后会显示“挑片完成”汇总；确认后程序自动进入“浏览”，停在当前照片，左右键可以逐张复查整批照片。
4. 复查确认无误后再点击“执行清理”，程序才按 J/R/X 决定把不保留的文件移入 Windows 回收站。

挑完以后按自己的需要继续：

- 想做后期：把 `arw` 目录导入 Lightroom 或其他 RAW 软件。这里的 Lightroom 只是后续选择之一。
- 想直接分享：从 `jpg` 目录复制照片到手机或社交平台。

“文件对应检查”会只读报告完整配对、仅 JPG、仅 RAW 和异常；由 J/R 清理主动形成的单格式文件属于正常结果。

## 主要功能

- “创建分类”在各照片实际父目录下分到 `jpg` / `arw`，“取消分类”还原到类型目录自己的父目录；保留日期层级，两者均不覆盖同名文件。
- 低干扰的网格视图和单张视图。
- 缩略图大小、筛选，以及名称/EXIF 拍摄时间排序。
- 四种互斥终态：`P` 双格式、`J` 仅 JPG、`R` 仅 RAW、`X/Delete` 全部废弃；再按一次相同按键可取消决定。
- 单张视图提供“挑片 / 浏览”导航：“挑片”让左右键及前后按钮只访问未决定照片，标记后跳到下一张未决定；最后一张完成后自动进入“浏览”，按当前排序逐张复查。切换目录时，有未决定照片就进入挑片，已全部决定就进入浏览。
- 重复当前旗标会取消决定并停留原图；“保留 / 废片”筛选只用于复查，不自动跳转。
- 左侧栏显示“已决定 / 总数”进度，以及紧凑的 `P 保留`、`X 废片`结果；未决定数量可由总数减去已决定数直接得出。
- 单张缩放、平移、导航器和底部胶片条。
- 显示日期、机型、ISO、焦段、光圈与快门。
- 只读检查 JPG/RAW 文件对应关系，并区分主动单格式与异常。
- 共享的持久缩略图缓存与拍摄时间缓存，减少重启、版本对比和清理后的重复加载。
- 所有清理进入 Windows 回收站，可恢复。
- 固定暗黑模式；统一深蓝按钮；记忆最近路径、当前视图、照片和缩放状态，并可从路径下拉菜单清除最近路径记录。
- 自动适配显示器工作区，兼容 4K 以及 1920×1080、150% 缩放环境。

## 快捷键

| 按键 | 功能 |
|---|---|
| `P` | 切换保留旗标 |
| `J` | 切换为仅保留 JPG |
| `R` | 切换为仅保留 RAW |
| `X` / `Delete` | 切换废片旗标，不立即删除 |
| `←` / `→` | “挑片”时切换上一张/下一张未决定照片；“浏览”时按当前排序逐张切换 |
| `Space` | 切换网格/单张视图 |
| `Ctrl` + 单击 | 扩展多选 |
| `Shift` + 单击 | 范围多选 |

## 安全规则

- 分类递归处理集合内 `.jpg`、`.jpeg`、`.arw`，仅在各自父目录移动，不跨 Collection Root，不跟随链接。
- 同名目标文件不会被覆盖。
- 配对按不区分大小写的相对目录 scope + 文件名主体判断，不跨日期配对；直接类型目录仅去掉一层。
- 程序不永久删除照片，清理均进入 Windows 回收站。
- “执行清理”只处理当前所选目录中的 J/R/X 决定及当前目录同名文件，不会混入其他照片目录的历史记录。
- 确认后仍会复核路径、决定、配对和文件时间戳；失败文件保留原决定并明确报告。
- 只有成功进入回收站的 JPG 才清除其 JPG 锚定状态；R 的 RAW 保留意图会在移动 JPG 前先落盘。
- “文件对应检查”只报告，不自动移动任何照片。

已知限制：分类按逐项检查点完成，不提供整批断电原子恢复；取消分类按当前类型目录还原，无法追溯程序外历史路径，空类型目录保守保留。网格文件列表重建后可能暂显示照片信息占位，重新选择或进入单张恢复。GPS 仍仅写 JPG，不支持 ARW/XMP；未知 private 布局会安全拒绝。

## 运行与构建

正式使用：双击 `RAWMate.exe`。程序不需要 Python，也不需要把图标或界面图片放在 EXE 旁边。

开发验证：

```bat
BUILD_RAWMate-Test.cmd
```

用户确认测试版后再构建正式版：

```bat
BUILD_RAWMate.cmd
```

构建使用 Windows 自带的 64 位 .NET Framework C# 编译器。完整流程见 [docs/TESTING.md](docs/TESTING.md) 与 [docs/RELEASE.md](docs/RELEASE.md)。

推荐把开发仓库克隆到 `C:\rawmate`。两台电脑均使用相同路径，可以减少脚本、快捷方式和交接说明的差异。

## 本机数据

界面状态、决定记录、派生缓存和错误日志保存在 `%LOCALAPPDATA%` 下，不包含照片本身，也不应提交到 GitHub。测试版继续使用兼容的 `RAWMate-Test-1.4` 独立设置/决定目录，只与正式版共享可丢弃的缩略图和拍摄时间缓存；旧 P/X 可迁移，旧版本中含义不同的 R 不会误读为“仅 RAW”。
