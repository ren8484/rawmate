# RAWMate PC UI 与交互规格

## 布局

- 主窗口默认约 1380×860，最小 1000×640。
- 左侧栏固定宽度约 320px，不随照片数量出现纵向滚动条。
- 右侧主区占剩余空间，网格和单张视图复用同一区域。
- 主区卡片接近窗口边缘，留白克制，不嵌套多层厚边框。

## 视觉

- 字体：Microsoft YaHei UI。
- 动作按钮使用统一蓝色体系，圆角约 5px；禁用态降低透明度。
- 主题按钮为圆形图标；浅色显示月亮，暗色显示太阳，图标应简洁。
- 网格/单张图标按钮圆角约 7px。
- 暗色背景层级清晰但不出现大白块；浅色模式输入框、菜单和文本有足够对比。
- 主滚动条为窄、深色、圆角的迷你样式，不显示粗白轨道或箭头按钮。

## 左侧栏

按顺序：

1. 品牌与主题按钮。
2. 照片目录、最近目录下拉、目录状态、选择目录。
3. JPG / RAW / 待分类统计与“分类”。
4. 操作：检查配对、选中项移至回收站、移除所有废片。

不要恢复已经删除的长篇“操作指南”占位文案。按钮是否保留应以是否具有独立业务语义为准，不只因按钮多而合并有确认语义差异的操作。

## 网格视图

- 顶栏：标题、筛选结果、筛选、排序、缩略图大小、自动前进、网格/单张切换。
- 缩略图保持 EXIF 正确方向并完整适配卡片。
- 单击选择一张；`Ctrl` 多选；`Shift` 从锚点范围选择。
- 双击进入单张视图。
- 选中态只使用一条清晰蓝色边框，不叠加突兀白框。
- 旗标与星级以紧凑徽标显示。
- 右键菜单项：打开原图、标记为保留、标记为废片、删除 JPG、删除 JPG + 同名 ARW。

## 单张视图

- 顶栏包含视图标题、当前文件名、自动前进、网格/单张切换。
- 图片以可用框为适应边界，尽量顶住预览框但不裁切。
- 左上角导航器显示整张图和当前视口，横竖构图均正确。
- 图片下方依次为缩放控制、适量间距、胶片条。
- 缩放输入文字为白色/高对比色，控件等距、统一圆角。
- 单击图片切换适应/200%；手动倍率保持到下一张。
- 右键菜单与网格保持相同功能。
- 照片信息位于主卡片下方，单行左对齐：日期、机型、ISO、焦段、光圈、快门。

## 方向与导航验收

每次改动图像管线、缩放或导航器，至少测试：

- 横构图 Orientation 1。
- 竖构图 Orientation 6。
- 反方向竖构图 Orientation 8。
- 镜像方向 2/4/5/7（可用合成样本）。
- 网格、单张、导航器、胶片条方向一致。
- 竖构图放大后拖动导航器，主图定位与视口框位置一致。

## 主题与 DPI 验收

- 浅色与暗色各启动一次。
- 100%、125%、150% Windows 缩放至少检查目标用户常用档位。
- 默认窗口、最小窗口、最大化窗口。
- 目录路径超长时不应破坏按钮布局。
- 大图库时左侧无滚动条，右侧只有一条迷你滚动条。
