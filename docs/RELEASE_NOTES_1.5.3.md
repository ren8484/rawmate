# RAWMate 1.5.3

修复网格顶栏在窄窗口、长统计摘要下挤出“单张视图”按钮的问题。摘要超宽时显示省略号，筛选、排序、缩略图大小及视图切换按钮保留独立空间；按钮尺寸、顺序和操作方式不变。

本次仅为局部UI修复，不改变GPS、递归扫描、分类、P/J/R/X、缓存、清理、事务和文件安全规则，不更改DPI Manifest或最小窗口尺寸。1.5.2仅为准备版本，按用户要求直接发布1.5.3。

验证：原21离线布局模型无按钮越界；366个边界模型/7692断言、78条UX/Grid、61条Cull通过。测试版与隔离正式EXE均完成独立资源启动、v1.5.3、窄窗口和Grid/单张实机冒烟。

已知限制G03：最小窗口下，底部第一行EXIF长文本末尾可能裁切，放大窗口可减少裁切。当前物理验收范围为3840×2160、200%；其余DPI、动态缩放和跨显示器迁移留待后续验证，不作为本次已验收修复的发布阻断项，也不代表这些环境已经通过。

下载仅包含RAWMate.exe。ExifTool继续由用户显式配置，不捆绑、不下载、不安装。
