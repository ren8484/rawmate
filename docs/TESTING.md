# RAWMate PC 测试指南

## 原则

- 先构建固定测试版，用户验收后再覆盖正式版。
- 文件操作测试只使用专门的临时目录和可恢复文件，不用唯一原片。
- “编译成功”不等于功能或界面正确。

## 1. 构建检查

```bat
BUILD_RAWMate-Test.cmd
```

通过条件：

- 编译器返回 0。
- 生成 `RAWMate-Test.exe`。
- EXE 可启动且标题为 RAWMate。
- 运行目录存在 `RAWMate.ico` 和 `RAWMateHeader.png`。

## 2. 最小安全夹具

创建专用目录，内容可复制自测试照片：

```text
test-data/
├─ PAIR01.JPG
├─ PAIR01.ARW
├─ pair02.jpeg
├─ PAIR02.arw
├─ ONLY_JPG.JPG
├─ ONLY_RAW.ARW
├─ ignored.txt
└─ nested/
   └─ MUST_NOT_MOVE.JPG
```

核验：

- 分类后两组配对进入正确目录。
- 扩展名和配对不区分大小写。
- `ONLY_JPG` 和 `ONLY_RAW` 被正确分类并在配对检查中分别报告。
- `ignored.txt` 和 `nested` 内文件不动。
- 预先制造目标同名冲突时不覆盖。
- “取消分类”将 `jpg` / `arw` 照片还原到根目录，并保持内容哈希不变。
- 创建或取消分类后，已有 JPG 的 P/X/星级标记仍绑定到移动后的正确路径。
- 根目录存在任一同名冲突时，“取消分类”在移动任何文件之前停止。
- 完整还原后只删除已经为空的 `jpg` / `arw` 文件夹。

## 3. 文件操作

- 右键“删除 JPG”只进入回收站 JPG，保留 ARW。
- 右键“删除 JPG + 同名 ARW”处理两者。
- 选中项批量清理包含同名 ARW。
- X 标废片后“移除所有废片”只处理废片及其同名 ARW。
- 取消确认时零文件移动。
- 锁定/无权限文件会出现在失败列表。
- 回收站中能看到并恢复测试文件。

## 4. 挑片与键盘

- 普通单击另一张只保留新选择。
- `Ctrl` 单击增加/移除单项。
- `Shift` 单击形成连续范围。
- `P` 与 `X` 互斥；重复按键取消旗标。
- `Delete` 只标废片，不立即移动文件。
- `0` 清除星级，`1`–`5` 正确显示。
- 开启自动前进后，`P`、`X/Delete`、`1`–`5` 标记完成只前进一张；`0` 不前进。
- `Caps Lock` 可切换自动前进，按钮状态同步，关闭重开后状态恢复。
- 自动前进按当前排序和筛选序列工作；到最后一张停止，不循环到第一张。
- 左右键在首尾循环。
- 空格双向切换视图，无明显单向延迟或崩溃。

## 5. 网格与性能

- 至少用 60 张 JPG 测试延迟缩略图。
- 滚动时缩略图逐步加载，界面可响应。
- 左侧固定区无滚动条。
- 右侧只有一条窄的迷你滚动条。
- 四档缩略图大小都不裁切文件名或徽标。
- 名称/EXIF 拍摄时间升降序正确；文件修改时间不得影响拍摄时间排序。
- 无有效 EXIF 拍摄时间的 JPG 在升序和降序中都排列在末尾，并以名称稳定排序。
- 五种筛选计数和内容正确。

## 6. 单张视图

- 双击和视图按钮均能进入，不退出应用。
- 默认“适应”尽量填满预览框且不裁切。
- 单击切到 200%，再次单击回到适应。
- 可输入 10%–600%；非法输入恢复当前显示。
- 放大后切换下一张仍保持相同比例。
- 图片可平移，导航器视口同步。
- 胶片条选择与主图同步。
- 连续左右切换时相邻图预载降低等待。

## 7. EXIF 与方向

按 `docs/UI_SPEC.md` 的方向矩阵测试横构图和竖构图。照片信息至少用真实 ILCE-6700 JPG 核验：

- 日期
- ILCE-6700
- ISO
- 焦段 mm
- f 值
- 快门秒数

缺失字段应显示 `—`，不能导致崩溃。

## 8. 状态恢复

设置一个非默认组合后关闭并重开：

- 固定暗黑模式，界面中没有主题切换按钮。
- 最近路径顺序。
- 网格尺寸和排序/筛选。
- 单张模式、当前照片和固定缩放倍率。
- P/X/星级。

确认均恢复；目录不存在时安全退回网格/空状态。

## 9. 视觉验收

实际启动测试版并截图检查：

- 暗黑模式。
- 横构图和竖构图。
- 网格和单张。
- 默认/最小/最大化窗口。
- 1920×1080、150% 缩放下首次启动窗口完整位于工作区内，左侧从“照片目录”到“移除所有废片”全部可见且没有滚动条。
- 1080p 与 4K 下目录/分类双列按钮不挤压文字，挑片进度数字与条内百分比完整显示；所有按钮保持 `#436794` 深蓝底且交互时不反转颜色。
- 目录路径输入区与下拉按钮外轮廓完整圆角；进度条分别在 0%、中间值和 100% 时检查左右端圆角，不能出现方角或溢出。
- 目标 Windows DPI。

任何滚动条、输入框、右键菜单、文字对比或方向问题都不能仅以“代码逻辑正确”判定通过。
