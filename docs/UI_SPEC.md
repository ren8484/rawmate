# RAWMate PC UI 与交互规格

GPS UX / Grid（1.5）：单张 GPS 行提供直接“设为来源 / 应用来源 / 当前来源”；网格增加轻量 GPS 三态标识和所选 JPG 操作。两种视图共享可清除的会话来源行，无来源时隐藏。ExifTool 配置移至左下角“设置 → GPS / 元数据”，显示状态、版本和完整路径；未配置应用时提示“取消 / 前往设置”。多选只弹一次分类汇总确认，默认缺失、已有需主动覆盖、来源永远跳过；统一逐张进度与取消剩余，最终一次成功/跳过/失败结果及详情。不增加快捷键。切根目录清空来源，同目录刷新保留有效来源，修改/删除立即失效。不改 P/J/R/X、排序/筛选/导航/缩放，仅失效目标 JPG 缓存，RAW / XMP 不处理。详见 [GPS_METADATA.md](GPS_METADATA.md)。

## 布局

- 主窗口在空间充足时默认约 1380×860；首次启动尺寸不得超过当前显示器工作区，需兼容 1920×1080、150% 缩放（约 1280×720 逻辑尺寸）。
- 空间充足时最小窗口约 1000×640；工作区小于该尺寸时，以当前工作区为动态下限，窗口不得伸到任务栏或屏幕外。
- 左侧栏固定宽度约 320px，不随照片数量出现纵向滚动条；内容始终从顶部开始排列，不因 4K 或高窗口产生顶部空白；可用高度不足时内容整体等比收紧，所有业务按钮仍须可见。
- 右侧主区占剩余空间，网格和单张视图复用同一区域。
- 主区采用平面工作区，不使用包裹主区的外层卡片；左侧与主区只用单条细分隔线划分，留白克制，不嵌套多层厚边框。

## 视觉

- 单张与多选共用的“应用 GPS”确认窗口底部统一为 `[应用] [取消]`，从左到右排列；应用保留 Primary 蓝底并为默认确认动作，取消使用低权重 Secondary 描边并支持 Esc。仅影响确认控件，不改变选择计划、覆盖规则或事务。

- 字体：Microsoft YaHei UI。
- 字重分层：章节标题、按钮、关键数字与 P/X 徽标使用 `SemiBold`；路径、辅助说明、统计标签和普通状态文字使用 `Regular`。辅助说明允许缩小约 1px 并降低灰度，但必须保持可读。
- 所有按钮统一使用深蓝色 `#436794`，不以悬停、按下或开关状态反转底色；状态用文字、细边框或透明度表达，禁用态降低透明度。
- 界面固定为暗黑模式，不显示主题切换按钮。
- 保留原生 Windows 标题栏及窗口行为，但标题栏使用与工作区连续的暗色背景、程序图标和白色 `RAWMate` 文字。
- 网格/单张图标按钮圆角约 7px。
- 暗色背景层级清晰，不出现大白块；输入框、菜单和文本有足够对比。
- 主滚动条为窄、深色、圆角的迷你样式，不显示粗白轨道或箭头按钮。

## 左侧栏

按顺序：

1. 照片目录、最近目录下拉、精简目录状态，以及同一行的“选择目录 / 刷新目录”；最近目录菜单底部提供圆角警示色“清除路径记录”按钮，按钮不挤占左栏宽度；左栏不再重复显示产品名和副标题。
2. JPG / RAW / 待分类统计使用三个等宽 `*` 列，每列的标题和精确数量都水平居中并围绕列中心增长；数值行使用 `Viewbox` + `StretchDirection.DownOnly`，短数字保持原字号，仅在五位数等内容超过列宽时等比收紧，禁止缩写、裁切或按字符数硬编码字号。同一行的“创建分类 / 取消分类”使用两个等宽 `*` 列。
3. 挑片进度：标题右侧显示“已决定 / 总数”，圆角进度条内显示百分比，下方只显示两个等宽 `*` 结果区：左侧 `[P] 保留 数量`向右增长，右侧 `[X] 废片 数量`向左增长，各自在列内侧边缘保留 12px。P/X 使用固定 18×18 的极浅彩色背景圆角徽标，字母以半粗体在徽标内水平、垂直居中；“保留 数量”与“废片 数量”分别位于同一个 `TextBlock` 的 Runs 中，统一字号和基线，标签为浅灰常规字重，数字为对应状态色半粗体。结果行与进度条间距约 14px。不使用固定坐标、按文字长度计算位置、数量缩写、✓/✕/○ 图标、未决定重复统计或整组状态块背景。
4. 操作：文件对应检查、选中项标记废片、执行清理。
5. 左下角固定显示当前产品版本，1.5.1 显示 `v1.5.1`；版本文字不随上方功能区居中，且从程序集信息版本自动生成。历史 1.5 按批准规格显示 v1.5。右侧轻量“设置”入口提供 GPS / 元数据工具配置。

目录路径输入区与右侧下拉按钮必须组成一个完整的圆角控件；进度条在 0%–100% 的所有状态下左右两端都保持圆角。

不要恢复已经删除的长篇“操作指南”占位文案。按钮是否保留应以是否具有独立业务语义为准，不只因按钮多而合并有确认语义差异的操作。

## 网格视图

- 1.5.1 保持平面 Grid；来自不同子目录的同名照片均显示，不分组、不按名称合并。分类按钮与递归待分类计数一致；在各自父目录创建 jpg/arw、还原，不聚合日期目录。轻量窗口显示后台计划/进度及取消剩余，确认/结果分别报告可移动与实际成功、冲突、跳过、失败。成功移动后保留决定、选中、当前照片和来源。GPS 图标设计和底部布局保持不变。

- 顶栏：标题、筛选结果、“全部 / 保留 / 废片 / 未决定”筛选、排序、缩略图大小、网格/单张切换；不显示自动前进开关。
- 顶栏筛选、排序、缩略图大小三个下拉菜单沿用自定义暗色圆角 ContextMenu 外层模板，与现有菜单项模板配套，不显示系统白色图标槽或装饰线；菜单选项与原点击行为保持不变。
- 缩略图保持 EXIF 正确方向并完整适配卡片。
- 缩略图下方的文件名保持单行居中并使用 `CharacterEllipsis`；超长名称不得撑宽卡片或影响相邻缩略图，悬停提示显示完整名称。
- 单击选择一张；`Ctrl` 多选；`Shift` 从锚点范围选择；从网格空白区域拖动可框选（Ctrl 保留原选中项）。
- 双击进入单张视图。
- 选中态只使用一条清晰蓝色边框，不叠加突兀白框。
- GPS 网格状态 UI 已冻结：有效 GPS 使用 Fluent Location 16 Filled（14px），无 GPS 使用现有一体式 Location Off 16 Filled（15px），当前会话来源使用官方 `assets/Location Ripple/SVG/ic_fluent_location_ripple_20_filled.svg`（15px）。优先级固定为 GPS Source > Has GPS > No GPS；每张只绘制一个 Path，不使用 Star、文字角标或 overlay。统一 20×20 暗色半透明小圆角容器，沿用现有浅蓝/灰蓝色系，不增加状态颜色。Tooltip 固定为“已有 GPS 信息 / 无 GPS 信息 / 当前 GPS 来源”。来源图标仅做约 1px 视觉尺寸微调；不再改图标设计，不挤压文件名，不改变选中蓝边框、选择处理或 GPS 业务行为。未经用户新授权不得重新评估或更换这套图标。
- P/J/R/X 决定以紧凑徽标显示；未决定状态不显示徽标。
- 右键菜单前四项依次为：标记为废片、保留双格式、保留 JPG、保留 RAW；不显示“打开原图”或快捷键字母，所有决定都不立即移动文件。分隔线后仅为“设为 GPS 来源 / 应用 GPS 到当前照片（或所选照片）”，不含 ExifTool 配置。
- 右键菜单普通项统一保持暗色，不用固定底色重复表达当前决定（当前决定由单张视图顶部状态显示）；鼠标移到哪一项，只有该行临时使用主按钮的 `#436794` 蓝色底与白字，移开立即恢复。不得使用白色、高亮灰或高饱和亮色作为选择背景，也不得显示系统白色焦点框或“栅栏”线。

## 挑片前进

- 自动前进保持启用且不占用 `Caps Lock`；单张视图顶栏提供“挑片 / 浏览”导航目标，它选择前后导航及标记后前进到哪里，不负责关闭自动前进。导航目标不做全局持久化：进入新目录时，有未决定照片则为“挑片”，已全部决定则为“浏览”，空目录默认为“挑片”。
- “挑片”下，左右键与前后按钮只在未决定照片间切换；在“全部 / 未决定”筛选下通过键盘 `P`、`X/Delete` 做出决定后，从完整图库按当前排序寻找下一张未决定照片，越过末尾后从开头继续。
- “浏览”下，左右键与前后按钮按当前排序逐张切换；在“全部 / 未决定”筛选下做出决定后，直接进入紧邻的下一张照片，越过末尾后从开头继续。
- 再按当前决定快捷键会把照片恢复为未决定，并停留在当前照片；浏览中取消决定仍保持浏览，并提示未决定数量及可切换到“挑片”继续处理。P/J/R/X 互相改判时，按当前“挑片 / 浏览”导航目标继续前进。
- “保留 / 废片”筛选是复查模式：修改旗标后只刷新结果，不跳往未决定照片，也不自动改变筛选条件。
- 只有当前操作让未决定数量从 1 变为 0 时，才停留在最后完成判断的照片并显示“挑片完成”，列出已决定、保留、废片以及 P/J/R 明细；用户确认后保持当前照片并自动切换到“浏览”，原筛选为“未决定”时同时恢复“全部”，确保整批照片立即可见。提示框只负责通知，不执行回收站操作；在已完成批次中改判不得重复弹出。

## 单张视图

- 顶栏包含视图标题、当前文件名、当前照片状态、“挑片 / 浏览”导航目标及网格/单张切换。右侧四个控件同高、等距并垂直居中；文件名只能占用中间的自适应列，单行居中并使用 `CharacterEllipsis`，超长名称不得覆盖或挤动右侧控件，悬停时应能查看完整名称。
- 当前照片状态只显示“双格式 / 仅 JPG / 仅 RAW / 废片 / 未决定”中文结果，不显示 P/J/R/X 快捷键前缀；快捷键提示保留在右键菜单和悬停说明中。
- 图片以可用框为适应边界，尽量顶住预览框但不裁切。
- 左上角导航器显示整张图和当前视口，横竖构图均正确。
- 图片下方依次为缩放控制、适量间距、胶片条。
- 缩放输入文字为白色/高对比色，控件等距、统一圆角。
- 单击图片在适应与检查倍率间切换：适应比例低于 100% 时检查倍率为 100%，达到或超过 100% 时检查倍率为 200%；任意非适应倍率下再次单击都直接返回适应。手动倍率保持到下一张。
- 单张视图切换照片目录时自动载入新目录排序后的第一张；新目录没有 JPG 时返回空图库，主图、导航器、胶片条和 EXIF 不得残留旧目录内容。
- “执行清理”成功移除当前 JPG 后，按清理前当前排序显示下一张仍存在的照片并在末尾回绕；当前 JPG 清理失败时保持当前照片。清理不得让其余缩略图整批回到占位状态。
- 右键菜单与网格保持相同功能。
- 照片信息位于主卡片下方，单行左对齐：日期、机型、ISO、焦段、光圈、快门。快门值不得直接显示未约分的 EXIF Rational；小于 1 秒显示最接近的 `1/N 秒`，大于等于 1 秒显示秒数。
- 单张与网格视图共用底部 GPS 行的独立 Grid 布局：“GPS 坐标/选中状态 │ 来源 文件名 · 坐标 [弹性留白] [清除] [设为来源] [应用来源]”。当前 GPS/状态在最左，来源紧随，操作固定最右；应用来源为蓝色主按钮，设为来源为低权重描边，清除为弱蓝底按钮。无来源时收起来源区、分隔线与清除，仅保留设为来源（无有效 GPS 时禁用）；当前就是来源时，来源坐标后显示低权重文字“当前来源”，右侧仅保留清除。网格多选显示选中数量，沿用原有选择及动作禁用条件；操作不再在顶部另占一行。来源文件名先省略，坐标最后压缩，不换行、不撑宽主区；第一行 EXIF 和 GPS 业务行为不变。

## 方向与导航验收

每次改动图像管线、缩放或导航器，至少测试：

- 横构图 Orientation 1。
- 竖构图 Orientation 6。
- 反方向竖构图 Orientation 8。
- 镜像方向 2/4/5/7（可用合成样本）。
- 网格、单张、导航器、胶片条方向一致。
- 竖构图放大后拖动导航器，主图定位与视口框位置一致。

## 暗黑模式与 DPI 验收

- 暗黑模式启动一次并确认不存在主题切换控件。
- 100%、125%、150% Windows 缩放至少检查目标用户常用档位。
- 默认窗口、最小窗口、最大化窗口。
- 1920×1080、150% 缩放下首次启动窗口完整位于工作区内，左侧从“照片目录”到“执行清理”全部可见且没有滚动条。
- 4K/高窗口下左侧“照片目录”必须贴近卡片顶部，删除品牌区后不得保留同等高度的顶部空白；多余高度只能留在操作按钮下方。
- 默认、最大化及低高度窗口下，左下角版本号都必须可见且不与操作按钮重叠；1.5.1 显示为 `v1.5.1`。
- 目录路径超长时不应破坏按钮布局。
- 大图库时左侧无滚动条，右侧只有一条迷你滚动条。
