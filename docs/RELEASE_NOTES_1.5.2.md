# RAWMate 1.5.2 — 发布说明草稿

状态：准备中，尚未发布。

后续决定：用户要求直接发布1.5.3，此文件仅保留未发布的准备草稿；最终说明见RELEASE_NOTES_1.5.3.md。

修复网格顶栏在窄窗口、长统计摘要下挤出“单张视图”按钮的问题。摘要超出可用宽度时显示省略号，筛选、排序、缩略图大小及视图切换按钮保持完整。按钮尺寸、顺序和操作方式不变。

本次仅为局部布局修复，不改变 GPS、递归扫描、分类、P/J/R/X、缓存、清理、事务或文件安全规则，也不更改 Windows DPI Manifest 或应用最小窗口尺寸。

验证包括原21个离线布局模型、366个宽度/摘要边界模型（7692断言）、78条UX/Grid及61条Cull回归。G01已在物理3840×2160、200%环境完成实机验收并获用户接受；本轮版本准备没有新增其他DPI测试。

已知限制：最小窗口下，底部第一行EXIF长文本末尾可能裁切（G03）；放大窗口可减少裁切。该限制保留。其他分辨率、DPI动态切换和跨显示器迁移仍待后续验证，不影响本次已验收局部修复的发布安排，也不代表这些环境已通过验收。

正式发布时仅提供RAWMate.exe；ExifTool继续由用户显式配置，不捆绑、不下载、不安装。此文档的正式状态、下载链接及资产SHA应在发布成功后填写。
